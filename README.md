# Cards

Приложение для заучивания слов по типу Anki: категории, карточки (слово +
перевод текстом и/или картинкой), оценки NEW/A–F и квиз с проверкой знаний.

## Стек

- Vue 3 + Vite (Composition API, `<script setup>`)
- Pinia — состояние (категории/карточки)
- Vue Router (hash-режим — важно для будущей сборки в Cordova/Capacitor,
  где приложение открывается из `file://`)
- Хранилище: IndexedDB (`idb-keyval`) — весь стейт лежит одним JSON-блобом

## Запуск

```bash
npm install
npm run dev
```

Продакшн-сборка (статический сайт, можно открыть просто как файлы):

```bash
npm run build
npm run preview
```

## Данные и бэкапы — важно

Все данные хранятся **только на этом устройстве** (в браузере через
IndexedDB). Если приложение когда-нибудь запакуют под iOS/Android и его
удалят с телефона — ОС гарантированно стирает всё приватное хранилище
приложения (и IndexedDB, и файлы в песочнице). Это ограничение самой
платформы, обойти его в вебе/Cordova/Capacitor нельзя.

Поэтому в разделе **Настройки** есть экспорт/импорт: кнопка
"Экспортировать данные" сохраняет один `.json`-файл со всеми категориями
и карточками, который можно вручную положить в iCloud Drive / Google
Drive / отправить себе на почту, а потом восстановить через
"Импортировать из файла" после переустановки. Рекомендуйте пользователю
делать это периодически, когда появится мобильная сборка.

## Cборка под iOS/Android

1. `npm install @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android`
   (Capacitor — активно поддерживаемый преемник Cordova, тот же принцип:
   WebView + нативная обёртка, но новее и удобнее для CLI-сборок)
2. `npx cap init` → `npx cap add ios` / `npx cap add android`
3. `npm run build` → `npx cap sync` → открыть в Xcode/Android Studio и
   собрать на подключённый телефон.
